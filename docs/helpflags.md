# Help Flags

Use the following flags when running the TUI:

| Flag | Description |
| :--- | :--- |
| `-change-dir` | Change directory before anything (default `"/home/username/src/orchard-tui"`) |
| `-db` | Path to sqlite db file (optional, for persistence; in-memory usage: `"file::memory:?cache=shared"`) |
| `-host` | Host URL ONLY if no env var |
| `-model` | Model ONLY if no env var |
| `-no-bash` | Remove bash tool, only use toolboxes |
| `-q` | Disable log |
| `-smoke` | Say hello and exit (no tools) |
| `-temperature` | Temperature (default 1) |
| `-thread` | Thread ID (if applicable) |
| `-v` | Enable log |
| `-version` | Show version info |
